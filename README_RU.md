# Чарлз Румменнигге — Telegram-бот

Бот отвечает от лица Чарлза, хранит историю и заметки в локальной базе SQLite, а иногда может писать первым.
Проект использует Python, Telegram Bot API и OpenAI Responses API.

## Что понадобится

- Компьютер, который может оставаться включённым, или сервер.
- Python 3.10+.
- Токен Telegram-бота от официального `@BotFather`.
- API-ключ OpenAI с доступом к API и оплачиваемым балансом/биллингом, если он требуется вашему аккаунту.

## 1. Создайте Telegram-бота

1. Откройте в Telegram официальный [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Задайте отображаемое имя, например `Charles Rummenigge`.
4. Придумайте уникальный username, который заканчивается на `bot`.
5. Скопируйте токен. Не отправляйте его другим людям и не публикуйте.

## 2. Получите ключ OpenAI API

Откройте [страницу API keys](https://platform.openai.com/api-keys), войдите в аккаунт и создайте ключ.
Доступ к ChatGPT и оплата ChatGPT-подписки не означают автоматически, что API включён или оплачен.
Не отправляйте ключ в Telegram и не вставляйте его в публичные файлы.

## 3. Установите Python и подготовьте папку

Распакуйте ZIP в отдельную папку.

Откройте терминал в папке проекта.

### Windows
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если PowerShell блокирует активацию, можно выполнить команды через `cmd`:
```bat
.venv\Scripts\activate.bat
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 4. Заполните настройки

Сделайте копию `.env.example` и назовите её `.env`.

Откройте `.env` в обычном текстовом редакторе и вставьте оба ключа:
```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
OPENAI_API_KEY=ключ_OpenAI
OPENAI_MODEL=gpt-5.5
PROACTIVE_MIN_HOURS=18
PROACTIVE_MAX_HOURS=36
```

Не добавляйте кавычки вокруг ключей. Не присылайте ключи мне или кому-либо ещё.

## 5. Запустите бота

В активированном окружении выполните:
```bash
python bot.py
```

Откройте чат с ботом по ссылке, которую дал BotFather, нажмите Start и отправьте сообщение.
Пока программа работает, бот отвечает. Если закрыть терминал или выключить компьютер, бот остановится.

## Память и команды

- База `charles_memory.sqlite3` хранит историю переписки локально.
- Долгосрочные заметки обновляются каждые 8 сообщений пользователя; в контекст ответа добавляются заметки и последние сообщения.
- `/memory` — посмотреть сохранённые заметки.
- `/forget` — удалить историю и долгосрочную память этого чата.
- `/proactive_on` и `/proactive_off` — включить/выключить инициативные сообщения.

Инициативные сообщения отправляются только после того, как пользователь сам запустил чат, и если включён режим `/proactive_on`.
Планировщик работает только пока программа запущена. Настройки интервала можно изменить в `.env`.
Это вероятностный механизм, поэтому бот не обязан писать в строго заданное время.

## Важные замечания

- Использование OpenAI API может стоить денег. Проверяйте лимиты и расходы в кабинете API.
- История хранится в локальном SQLite-файле на устройстве/сервере, где запущен бот. Сделайте резервную копию, если она важна.
- При использовании API часть текста отправляется провайдеру для генерации ответа. Не передавайте боту пароли, платёжные данные и другие секреты.
- Для постоянной работы 24/7 потребуется хостинг/VPS или другой постоянно работающий компьютер.
- Бот не отправляет сообщения первым до тех пор, пока пользователь не открыл чат и не нажал Start.

## Если что-то не работает

- `Не заполнен TELEGRAM_BOT_TOKEN` — проверьте имя `.env` и значение токена.
- `Не заполнен OPENAI_API_KEY` — добавьте API-ключ.
- Ошибки авторизации или оплаты — проверьте ключ, доступ к API, биллинг и выбранную модель в кабинете провайдера.
- `ModuleNotFoundError` — убедитесь, что виртуальное окружение активировано и выполнен `pip install -r requirements.txt`.
